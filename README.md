# arduino-acceleration-and-steering-with-joystick-
One joystick module controls a DC motor for acceleration and a Servo Motor for steering. Extreme Bare Bones RC Car project

-Components-

Arduino Mega 2560 Microcontroller

3-6V DC Motor

9G Servo Motor with motor attachment

Joystick Module

Breadboard

9V Battery

Jumper Wires

Male to Female Wires

L293D Chip

-Libraries-
Built in Arduino Servo Library (Servo.h)


-IMPORTANT-
Circuit Diagram shows an Arduino UNO R3, the Components and Code use an Arduino Mega. Update Code depending on Arduino model
Circuit diagram does not have a proper Joystick module, it is represented by a mini Breadboard with comments dictating the pin locations, Match the wiring and pins according to your Joystick Module
